## ✨ Features — 8+ Features

| # | Feature | What It Does |
|---|---------|--------------|
| 1 | **Sorting Visualizer** | Bubble, Selection, Insertion, Merge, Quick, Heap Sort with live bars, comparisons, swaps and time |
| 2 | **Searching Visualizer** | Linear Search + Binary Search (Sorted) with step-by-step highlighting |
| 3 | **Stack** | Push, Pop, Peek, Clear — LIFO visual |
| 4 | **Queue** | Enqueue, Dequeue, Clear — FIFO visual |
| 5 | **Linked List** | Add at Head, Add at Tail, Remove Head, Remove Tail, Clear — Node + Arrow visual |
| 6 | **Binary Search Tree** | Insert, Clear, Inorder, Preorder, Postorder |
| 7 | **Graph - BFS / DFS** | Run BFS from A, Run DFS from A, Reset — Queue vs Stack logic |
| 8 | **DSA Quiz - Practice Mode** | 10 Questions, Score, +20 points per correct answer, Start / Next / Reset |
| 9 | **Interview Tip** | Time Complexity — Bubble = O(n²), Merge / Quick = O(n log n), Binary Search = O(log n) |

## 🚀 How To Run

### Option 1 — GitHub Pages (Live)
1. Upload `index.html` to this repo
2. Go to **Settings → Pages → Branch: main → Save**
3. Open: `https://ammarahmed-star.github.io/DSA---Visualizer/`

### Option 2 — VS Code (Local)

## 🎮 How To Use

1. **Sorting:** Algorithm choose karo → Size / Speed set karo → `Start Sorting` dabao
2. **Searching:** Value daalo → Linear / Binary choose karo → `Search` dabao
3. **Stack / Queue / Linked List:** Value daalo → Push / Enqueue / Add dabao
4. **Tree:** Value daalo → Insert → Inorder / Preorder / Postorder dabao
5. **Graph:** `Run BFS` ya `Run DFS` dabao — traversal dekho
6. **Quiz:** `Start Quiz` → Answer choose karo → `Next Question`
